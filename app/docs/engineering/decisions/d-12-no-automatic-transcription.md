# D-12 — No automatic transcription or summarisation

**Status:** Accepted

## Context

The zero-cost and no-account-per-person constraints rule out both ways of
getting an automatic transcript: a local tool would require every volunteer
to install and run command-line software on their own machine, and a hosted
one would require a subscription, which needs a billing owner.

## Decision

No transcription or summarisation tool is provided, automatic or otherwise.

## Rejected

Both a locally run tool and a hosted subscription service — each violates a
different one of the project's constraints.

## Cost

Producing a discussion summary after a session is manual note-taking by the
hosts, not a by-product of a tool that was transcribing anyway. Any workflow
material written on the assumption that a transcript already exists needs to
be written for manual notes instead.
