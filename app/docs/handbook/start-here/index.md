## The series in three lines

We run online behavioural-science webinars — Thursdays, 12:30 CET. Volunteers find the speakers, prepare each event, host it, and follow up. Everything we do is in this handbook.

## The roles

- **Contributor** — anyone. Suggest a speaker, pick up a task, lend a hand.
- **Event Host** — runs a webinar; each webinar has two.
- **Editorial Board** — validates speakers and steers the series.
- **Architecte** — looks after the system itself.

See [Roles](../roles.md) for the detail.

## The way we work

- **Act without asking.** The step-by-step guides hand you the templates — just go.
- **Two green lights only.** Validating a speaker and publishing a recording need the Board's nod. Nothing else does.
- **Everything is visible.** Each webinar's progress is open to all, so a task is never lost.
