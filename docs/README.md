# Documentation, by reader

Three trees, and which one is yours depends on what you are doing today.

| tree | written for |
|---|---|
| [`handbook/`](handbook/index.md) | a volunteer running a webinar |
| [`operating/`](operating/index.md) | the operator who stands an instance up and keeps it running |
| [`engineering/`](engineering/index.md) | somebody changing this code, or deciding whether to build on it |

Each index opens with what its tree holds, what it does not, and where the
other two are.
