# After the webinar — checklist

Run this in the days after the webinar. Details: [Phase 4 — After the webinar](../workflow/4-after.md).

- [ ] **Transcript saved** (the Zoom live-transcript file)
- [ ] **Recording sent** to the YouTube contact (TEATIME channel)
- [ ] **Summary posted** on the forum thread
- [ ] **Recording published** on YouTube — only after the Board's green light
- [ ] **Thank-you** sent to the speaker
- [ ] **Numbers noted** in the event list (registrations, peak attendance, YouTube views, forum replies)
- [ ] **Handbook improved** — fix anything that was unclear or could be smoother
