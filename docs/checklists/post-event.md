# Post-event checklist

Run this in the days following the webinar. See [Phase 4 — After the webinar](../workflow/4-after.md) for the detail.

- [ ] **Transcript saved** (Zoom live transcript `.txt`)
- [ ] **Recording sent** to the YouTube responsible (TEATIME channel)
- [ ] **Discussion summary posted** on the forum thread
- [ ] **Recording published** on YouTube — only after 🚪 Gate 2 (Publication) is cleared
- [ ] **Thank-you email** sent to the speaker
- [ ] **Metrics recorded** in `data/events.yml` (registrations, live peak, YouTube views, forum replies)
- [ ] **Runbook updated** — fold back anything that went wrong or could be smoother. This is what keeps the handbook alive.
