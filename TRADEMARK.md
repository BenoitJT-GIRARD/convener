# The name and the marks

The name **Convener** and the mark in `assets/brand/convener/` are **not** covered by
the licence. Everything else in this repository is — see [`LICENSE`](LICENSE),
whose additional term under section 7 of the GNU Affero General Public License
states that refusal in the licence's own language.

## The rule

Fork it, run it, change it, host it, charge for hosting it — and rename it.

The licence is there so anybody may have the code. The name is there so a
person reading it knows whose code they are running.

## What is covered

- The name **Convener**, however it is cased or spaced, and any name a reader
  would confuse with it.
- The mark and the wordmark this repository distributes in `assets/brand/convener/`
  — the two arcs closing on a dot, the banner lock-up, and their single-ink
  variants.

## What is not covered

- **The code, the documentation, the configuration, the workflows.** The
  licence covers all of it.
- **An instance's own identity.** A series' name, an organisation's logo, the
  palette in `instance/data/brand.json`: those belong to whoever runs that
  instance. D-16 is where the two charters are kept apart.
- **Saying true things.** "Built on Convener", "a fork of Convener", "imports
  Convener's certificate format" — an accurate description of an origin.

## What a fork changes

1. The repository's name, and whatever the fork calls itself in public.
2. `product` in `NOTICE.json` — the name in the notice both interfaces
   display in their footer.
3. Nothing else in that file. `copyright` stays: sections 4 and 5 of the
   licence require the notices to be kept intact, and a fork's own copyright
   line goes beside that one.

## What this is worth

**The mark is unregistered**, and there is no registration planned.

An unregistered name can be defended in the United Kingdom by an action for
passing off; across the European Union the nearest equivalents are national
unfair-competition rules, and there is no EU-wide unregistered right at all.
Every one of those routes turns on proving that the public already associates
the name with this work and that somebody's use of it misleads them — a claim
about reputation, proved case by case, after the harm, at a cost this project
does not have.

**Only a registration constrains anybody in advance.** An EU trade mark filed
electronically at the EUIPO in a single class costs about €850, against a
founding constraint that this project costs nothing to run. Hence no
registration; the decision is reversible.

**Registration stays possible only while the name is still capable of being a
mark**, and two things end that quietly:

- Somebody else registering the same or a similar name for similar goods
  first. The earlier right is then theirs.
- The name sliding into being the ordinary word for the thing. `convener` is
  already an ordinary English word — the person who convenes a meeting —
  which makes it a weak mark for software whose job is convening meetings. A
  descriptive name is refused registration unless distinctiveness acquired
  through use can be shown, and every year the word is used generically for
  this kind of software makes that showing harder.

**So this file asks.** It tells a good-faith fork what to rename and why, and
it puts the copyright holder's refusal to license the name on the record,
which is where a refusal has to sit if it is ever to matter. Against somebody
who does not care, it does nothing today.
