# The name and the marks

The name **Convener** and the mark in `brand/convener/` are **not** covered by
the licence. Everything else in this repository is — see [`LICENSE`](LICENSE),
whose additional term under section 7 of the GNU Affero General Public License
is where this refusal is stated in the licence's own language.

## The rule, in one line

Fork it, run it, change it, host it, charge for hosting it — and rename it.

That is what Rust, Python and Docker each do with their own names, for the
reason all three give: the licence exists so anybody may have the code, and
the name exists so a person reading it knows whose code they are running.
Those two purposes only collide when one name ends up on two different
programs.

## What is covered

- The name **Convener**, however it is cased or spaced, and any name a reader
  would confuse with it.
- The mark and the wordmark this repository distributes in `brand/convener/`
  — the two arcs closing on a dot, the banner lock-up, and their single-ink
  variants.

## What is not covered

- **The code, the documentation, the configuration, the workflows.** The
  licence covers all of it, in full, with nothing held back and no field of
  use excluded.
- **An instance's own identity.** A series' name, an organisation's logo, the
  palette in `instance/data/brand.json`: those belong to whoever runs that instance and
  never to this project. D-16 is where the two charters are kept apart, and
  the product claims nothing over the instance's.
- **Saying true things.** "Built on Convener", "a fork of Convener",
  "imports Convener's certificate format" — describing an origin accurately is
  not branding a fork with the name, and nothing here asks anybody to stop.

## What a fork actually changes

Three things, and the third is the one people get backwards:

1. The repository's name, and whatever the fork calls itself in public.
2. `product` in `NOTICE.json` — the name in the notice both interfaces
   display in their footer.
3. **Not the copyright line beside it.** `copyright` in that same file is not
   a fork's to remove: sections 4 and 5 of the licence require the notices to
   be kept intact, and a fork that adds its own copyright line adds it
   *beside* that one. Renaming the product and erasing its authorship are
   different acts, and only the first is being asked for.

## What this is worth

A document claiming more protection than it has is worse than no document, so:

**The mark is unregistered.** There is no registration anywhere, and there is
not going to be one soon.

An unregistered name is not nothing, and it is not much either. In the United
Kingdom it can be defended by an action for passing off; across the European
Union the nearest equivalents are national unfair-competition rules, and there
is no EU-wide unregistered right at all. Every one of those routes turns on
proving that the public already associates the name with this work and that
somebody's use of it misleads them. That is a claim about reputation, proved
case by case, after the harm, at a cost this project does not have.

**Only a registration constrains anybody in advance.** An EU trade mark filed
electronically at the EUIPO in a single class costs about €850. This project's
founding constraint is that it costs nothing to run — no server, no database,
no subscription — and €850 is not nothing. So there is no registration. That
is a decision, and it is reversible.

**Registration stays possible only while the name is still capable of being a
mark**, and two things end that quietly:

- Somebody else registering the same or a similar name for similar goods
  first. The position then reverses, and the earlier right is theirs.
- The name sliding into being the ordinary word for the thing. `convener` is
  already an ordinary English word — the person who convenes a meeting —
  which makes it a weak mark for software whose job is convening meetings. A
  descriptive name is refused registration unless distinctiveness acquired
  through use can be shown, and every year the word is used generically for
  this kind of software makes that showing harder rather than easier.

**So what this file does is ask.** It tells a good-faith fork what to rename
and why, and it puts the copyright holder's refusal to license the name on the
record, which is the only place a refusal can sit if it is ever to matter.
Against somebody who does not care, it does nothing at all today. Claiming
otherwise is the one failure this file cannot afford.
